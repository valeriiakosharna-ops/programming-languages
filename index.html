Напиши свою програму в редакторі нижче. Ми виконаємо її в навчальній браузерній пісочниці, а малюнок або текст ти побачиш праворуч у полі «Твій результат» (на телефоні — під редактором).

Це не повноцінна IDE: доступні бібліотеки, робота з файлами, швидкість і поведінка виконання можуть відрізнятися. Інтерактивне введення через input, prompt або Scanner поки не підтримується. Нічого встановлювати не потрібно.

03 / ЗНАЙОМСТВО БЕЗ ЗАВДАНЬ

Ще дві мови. Два різні підходи.

Тут не потрібно нічого розв’язувати. Прочитай приклад і запусти демонстрацію, щоб побачити, як працює мова.

TS

TypeScript

JavaScript із перевіркою типів

Тип описує, яке значення ми очікуємо: наприклад, текст або число. TypeScript перевіряє код перед запуском і перетворює його на JavaScript — саме JavaScript виконує браузер.

Де використовують

Вебінтерфейси, великі JavaScript-проєкти та серверні застосунки на Node.js. Типи допомагають знаходити помилки ще під час розробки.

Як працює цей приклад

Friend описує друга з текстовим ім’ям. Функція greet створює привітання. Увімкни помилку типу — замість імені з’явиться число, і перевірка зупинить виконання.

TypeScript → перевірка → JavaScript → результат
Тут з’явиться привітання або повідомлення про помилку.
Який JavaScript отримав браузер?


Rb
Ruby
Виразна мова з лаконічним синтаксисом
Ruby — динамічна мова: тип значення визначається під час виконання. Інтерпретатор виконує програму, а код часто читається як опис дій.
Де використовують
Вебзастосунки з Ruby on Rails, автоматизація та скрипти. Rails — фреймворк, який допомагає будувати вебзастосунки на Ruby.
Як працює цей приклад
Масив names містить два імені. each перебирає їх по одному. puts виводить рядок, а #{name} підставляє поточне ім’я в текст. Тут не потрібен фреймворк Rails.
Ruby → інтерпретатор → результат
Тут з’являться два персональні привітання.
