# NIX · Перший код

Україномовний навчальний тренажер для новачків: Python, JavaScript і Java, два рівні, коротка теорія, редактор і візуальні картки результату. Логотип у `assets/logo.svg` — векторне відтворення наданого зображення.

## Запуск

Потрібні Python 3.10+, Node.js 18+ та **JDK 11+** (не лише JRE). Зовнішні бібліотеки й платні API не використовуються. Шрифт Manrope завантажується з Google Fonts, за відсутності мережі використовується системний шрифт.

```sh
cd /workspace/programming-languages
python3 server.py
```

Відкрий `http://127.0.0.1:8000` у своєму браузері. HTML потрібно відкривати через сервер: він виконує справжній Python/JavaScript і компілює та запускає Java. Приклади можна редагувати й запускати кнопкою або Ctrl/Cmd + Enter. Tab додає відступ. Чернетки кожної мови й рівня зберігаються до перезавантаження сторінки.

## Межі використання

Сервер призначений **лише для власного коду на локальному комп’ютері** та слухає loopback. Обмеження часу й розміру виведення не є пісочницею: код має права поточного користувача, доступ до його файлів і мережі. Не публікуй цей сервер в інтернеті та не запускай недовірений код. Для публічного навчального сайту потрібен окремий ізольований сервіс виконання коду.

Картки відображають стандартне текстове виведення програми; HTML у виведенні не виконується. Перший рівень — привітання, другий — змінна, цикл і сходинки з емодзі.
