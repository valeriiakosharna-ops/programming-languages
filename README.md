# NIX · Перший код

Україномовний тренажер для людей без досвіду й тих, хто тільки починає: Python, JavaScript та Java, два рівні, коротка теорія, редагування програм і кольорові картки результату.

**Учням потрібен лише браузер і посилання. Жодних установок, реєстрацій, ключів API чи команд.** Усі три мови працюють у браузері. Програми не надсилаються на сервер виконання коду.

## Публікація на GitHub Pages

1. Додай файли цієї гілки в `main` через pull request.
2. У репозиторії відкрий **Settings → Pages → Build and deployment → Source** і вибери **GitHub Actions**.
3. У **Actions** запусти **Build and deploy trainer to GitHub Pages** на `main`, або дочекайся автоматичного запуску після наступного push у `main`.
4. Після успішного deploy поділися посиланням, яке покаже GitHub Pages. Для цього репозиторію очікуваний шлях — `https://valeriiakosharna-ops.github.io/programming-languages/`.

Workflow `.github/workflows/pages.yml` сам встановлює залежності, збирає статичну папку `dist`, перевіряє роботу в браузері й публікує її. Pull request перевіряє збірку та тести, але не публікує сайт. У приватному репозиторії доступність Pages залежить від тарифу GitHub.

## Як працює виконання

- **Python** — справжній CPython у WebAssembly через Pyodide 0.27.7; базова стандартна бібліотека входить у збірку.
- **JavaScript** — рушій браузера в окремому Web Worker.
- **Java** — компілятор OpenJDK 8 (`javac`) та DoppioJVM у Web Worker. Це Java 8, тому приклади не використовують новіші методи, наприклад `String.repeat`.

Усі потрібні ресурси, включно зі шрифтом, публікуються на тому самому Pages-сайті. Немає стороннього сервісу виконання, платного API або потреби в COOP/COEP-заголовках. Python і Java завантажуються автоматично під час першого запуску. Java має більший пакет (приблизно 38 МБ), тож перший запуск може зайняти десятки секунд на повільному з’єднанні або телефоні. Статус завантаження й кнопка «Зупинити» доступні в інтерфейсі.

Виконання програми обмежене 7 секундами, завантаження та компіляція — 120 секундами; кількість виведення обмежена. Нескінченний цикл можна зупинити без перезавантаження сторінки. HTML у результаті показується як текст. Чернетки різних мов і рівнів зберігаються протягом відкритої сесії. Додаткові Python-пакети, графічні Java-застосунки та встановлені на комп’ютері бібліотеки не є частиною цього навчального тренажера.

## Для розробника (учням це не потрібно)

Середовище збірки: Node.js 22, Python 3, curl, tar. На GitHub Actions вони надаються автоматично; JDK не потрібен навіть для збірки сайту.

```sh
npm ci --ignore-scripts
npm run build
npm run serve
```

Папка `dist/` — готовий статичний сайт. Локальний HTTP-сервер потрібен тільки для перегляду розробником, оскільки браузери не завантажують Web Workers і WebAssembly через `file://`.

```sh
npx playwright install chromium
npm test
```

Браузерні тести перевіряють усі шість прикладів і їх редагування, помилки синтаксису, зупинку, ліміти, мобільний вигляд і роботу під шляхом `/programming-languages/`. Тести використовують тільки статичний сервер: жодного `/api/run` не існує.

Залежності npm зафіксовані lockfile; старий install-hook Doppio не запускається. Збірка завантажує фіксований Java-архів з офіційного GitHub release та перевіряє SHA-256 перед розпакуванням. Ліцензії й посилання на вихідні коди — в `licenses/`.

Логотип `assets/logo.svg` — векторне відтворення наданого зображення.
