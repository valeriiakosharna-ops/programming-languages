# NIX · Перший код

Україномовний тренажер для людей без досвіду й тих, хто тільки починає. **Учням потрібен лише браузер і посилання.** Немає встановлень, реєстрації, ключів API або серверного виконання коду.

## Що є на сторінці

- Пояснення «твій код → браузерна пісочниця → твій результат» і відмінностей від IDE.
- П’ять мов для практики: **Python, JavaScript, Java, C++ і PHP**.
- Два рівні: квадрат із команд руху та повороту; спіраль зі змінною й циклом.
- Кольорове SVG-полотно з черепашкою, редагування коду, зупинка, текстова консоль і підказки.
- Окремі демонстрації **TypeScript** (перевірка типів, отриманий JavaScript, виконання) та **Ruby** (масив і перебір імен) з поясненнями застосування.
- Чотири корисні посилання: рейтинги DOU і Stack Overflow 2026, W3Schools, навчальні ресурси NIX.

## Публікація на GitHub Pages

1. Об’єднай цю гілку з `main` через pull request.
2. У **Settings → Pages → Build and deployment → Source** вибери **GitHub Actions**.
3. Workflow **Build and deploy trainer to GitHub Pages** автоматично збере й перевірить сайт після push у `main`. Його також можна запустити вручну на `main`.
4. Поділися посиланням із успішного deploy. Очікуваний шлях для цього репозиторію: `https://valeriiakosharna-ops.github.io/programming-languages/`.

`.github/workflows/pages.yml` встановлює залежності, збирає `dist/`, запускає браузерні тести й публікує тільки готовий статичний сайт. Pull request перевіряється без публікації. У приватному репозиторії доступність Pages залежить від тарифу GitHub.

## Середовища виконання

| Мова | Реальне виконання в браузері |
| --- | --- |
| Python | CPython через Pyodide 0.27.7 / WebAssembly |
| JavaScript | Рушій браузера в окремому Web Worker |
| Java | OpenJDK 8 `javac` + DoppioJVM |
| C++ | Clang 8, C++17, компонування у WebAssembly та WASI |
| PHP | PHP 8.2.0 / WebAssembly та WASI |
| TypeScript | TypeScript 5.8.3 перевіряє типи та компілює код; результат виконує JavaScript |
| Ruby | Ruby 3.2.0 / WebAssembly та WASI |

Усі середовища та шрифт розміщуються на тому самому Pages-сайті. Код не надсилається стороннім сервісам виконання. COOP/COEP-заголовки й SharedArrayBuffer не потрібні. Завантажується тільки вибране середовище; перший запуск важчих мов може зайняти десятки секунд, особливо на телефоні або повільному з’єднанні. Для Java потрібно близько 38 МБ, для C++ — близько 61 МБ із бібліотеками. Загальний сайт більший, але браузер не завантажує всі мови одразу.

## Навчальна черепашка

Бібліотека цього тренажера підтримує `forward`, `right`, `left`, `color`, `penup`, `pendown`. Значення довжини — пікселі, кута — градуси, колір — hex `#RRGGBB`.

- Python: `from turtle import forward, right, color` або навчальний `turtle.Turtle()`.
- JavaScript: об’єкт `turtle` надається середовищем.
- Java: допоміжний клас `Turtle`, код учня — `public class Main`.
- C++: `#include "turtle.h"`, простір імен `turtle`.
- PHP: `require 'turtle.php';`.

Це навчальний міст до SVG, а не повна реалізація desktop turtle або стандартна бібліотека всіх мов. Справжній інтерпретатор/компілятор виконує введений код; бібліотека передає команди малювання сторінці. У звичайній IDE потрібна відповідна графічна бібліотека. Простий довільний код із `print`, `console.log`, `System.out.println`, `std::cout` або `echo` також працює та створює текстові картки.

## Обмеження пісочниці

Код запускається у фонових Web Workers. Вони не мають прямого доступу до DOM сторінки; це навчальна браузерна ізоляція, а не окрема ОС. Середовище не замінює IDE: сторонні пакети, мережеві/графічні бібліотеки, локальні файли й desktop API можуть бути недоступними. Інтерактивне введення `input`/`prompt`/`Scanner` поки не підтримується. Java підтримує синтаксис Java 8, C++ — C++17 для WASI.

Виконання обмежене 7 секундами; завантаження й компіляція — 120 секундами. Кнопка «Зупинити» завершує Worker навіть у нескінченному циклі. Виведення обмежене; малюнок відображає до 200 команд, картки — до 40 рядків. HTML у виведенні не виконується. Чернетки мов і рівнів зберігаються до перезавантаження сторінки.

## Для розробника (учням це не потрібно)

Збірка: Node.js 22+, Python 3.12+, curl, tar. На GitHub Actions вони надаються автоматично; JDK, Clang, PHP або Ruby на машині не потрібні.

```sh
npm ci --ignore-scripts
npm run build
npm run serve
```

`dist/` — готовий статичний сайт. Локальний HTTP-сервер потрібен тільки розробнику: браузери не завантажують Web Workers/WebAssembly через `file://`.

```sh
npx playwright install chromium
npm test
```

Тести використовують статичний сервер під `/programming-languages/`: перевіряють 10 графічних прикладів, зміни програм, демонстрації TypeScript/Ruby, помилки, зупинку, ліміти, мобільну версію та посилання. Жодного `/api/run` немає.

Версії npm зафіксовані lockfile; старий install-hook Doppio не запускається. Java-архів і додаткові WASM-середовища завантажуються з фіксованих upstream-джерел через HTTPS та перевіряються за SHA-256. Ліцензії та посилання на вихідні коди — в `licenses/`.

Логотип `assets/logo.svg` — векторне відтворення наданого зображення. Інтерфейс використовує надану палітру NIX.
